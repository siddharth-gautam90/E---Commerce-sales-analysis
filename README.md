# 📊 E-Commerce Sales & Profitability Analysis

An Exploratory Data Analysis (EDA) project focused on understanding sales performance, profitability, customer segments, and regional trends using Python.

---

## 📌 Project Overview

This project analyzes an E-Commerce Superstore dataset containing **9,994 transaction records** covering the period **2014–2017**.

The primary objective is to explore business performance through data analysis, identify important sales and profitability trends, and generate meaningful business insights that can support data-driven decision-making.

Using Python and interactive visualizations, this project investigates product performance, customer segments, regional sales, discount patterns, and loss-making products.

## 🔍 Business Questions & Analysis

This project answers 12 business questions:

| No. | Business Question                                        | Analysis                     |
| --- | -------------------------------------------------------- | ---------------------------- |
| 01  | What are the monthly sales trends?                       | Monthly Sales Analysis       |
| 02  | Which product category generates the highest sales?      | Sales by Category            |
| 03  | Which sub-categories generate the highest sales?         | Sales by Sub-Category        |
| 04  | What are the monthly profit trends?                      | Monthly Profit Analysis      |
| 05  | Which category generates the highest profit?             | Profit by Category           |
| 06  | Which sub-categories generate the highest profit?        | Profit by Sub-Category       |
| 07  | How do sales and profit vary across customer segments?   | Segment Analysis             |
| 08  | How does the sales-to-profit ratio vary across segments? | Profitability Analysis       |
| 09  | Which states generate the highest sales?                 | State-wise Sales Analysis    |
| 10  | Which regions generate the highest profit?               | Regional Profit Analysis     |
| 11  | How are discounts associated with profitability?         | Discount vs. Profit Analysis |
| 12  | Which products generate the highest losses?              | Loss-Making Product Analysis |

---

## 📈 Key Business Insights

The analysis revealed several important findings:

* **Technology** generated the highest sales among the three product categories.
* **November 2017** recorded the highest monthly sales.
* **December 2016** recorded the highest monthly profit.
* **California** was the highest sales-generating state.
* Monthly sales and profit did not always peak during the same period.
* Discount levels and loss-making products were examined to identify potential profitability improvement opportunities.


### 5. Run the analysis

Open `E Commerce sales Project.ipynb` and execute the notebook cells.
