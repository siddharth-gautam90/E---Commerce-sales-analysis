# E-Commerce Sales & Profitability Analysis

## Project Overview

This project focuses on analyzing an e-commerce Superstore dataset containing 9,994 transaction records from 2014 to 2017.

The objective is to evaluate sales performance, profitability, customer segments, product categories, and regional performance using Python.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Plotly
* Jupyter Notebook
* Exploratory Data Analysis (EDA)

## Business Questions

This project answers 12 business questions:

1. Monthly Sales Analysis
2. Sales by Product Category
3. Sales by Sub-Category
4. Monthly Profit Analysis
5. Profit by Category
6. Profit by Sub-Category
7. Sales and Profit by Customer Segment
8. Sales-to-Profit Ratio by Segment
9. Sales Performance by State
10. Profit Analysis by Region
11. Discount Impact on Profitability
12. Loss-Making Product Analysis

## Key Business Insights

* Technology generated the highest sales among the three product categories.
* November 2017 recorded the highest monthly sales.
* December 2016 recorded the highest monthly profit.
* California was the highest sales-generating state.
* Sales and profitability did not always peak during the same month.
* Discount levels and loss-making products were examined to identify potential profitability improvement opportunities.

## Project Structure

* data/: Dataset
* notebooks/: Jupyter Notebook containing analysis
* visuals/: Data visualizations

## Conclusion

The project demonstrates how Python-based data analytics can be used to identify
 business trends, evaluate profitability,
 and generate actionable insights from e-commerce transaction data.
